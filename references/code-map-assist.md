# 项目代码地图联动

仅在本技能实际执行项目审查时使用。调用已安装的 `project-code-map`，读取其主文件及当前模式需要的引用；不要复制另一套建图格式或预设具体游戏架构。这是审查期间的辅助步骤，不是后台监控任务。

## 先判断项目与地图状态

1. 确认本次审查的项目根与范围。读取已安装 `project-code-map` 的 `references/storage.md`，使用其路径工具定位默认外部索引；用户明确指定位置时优先遵循。核对索引记录的项目根，不能只凭同名目录匹配。外部地图缺失时再查项目指导指向的旧地图或 `docs/code-map/INDEX.md`；需要维护时按辅助技能规则保存到外部位置，保留仓库内原件。每个项目独立判断，不能凭“本会话已建过图”跳过另一项目。
2. 有地图时读取其范围、revision 与相关工作区状态，结合当前改动和本次目标核对时效；同时考虑已提交、暂存、未暂存与相关未跟踪文件。相同 HEAD 不能证明工作区没变。没有 Git 或旧基线不可比较时，直接回查相关入口、注册和依赖。
3. 同一审查对象及已核实的代码快照内复用检查结果；用户切换项目、出现新代码变化或审查扩展到未覆盖模块时再判断。不每轮重复加载全部地图或扫描整个仓库。

## 调用决策

| 当前证据 | 辅助行为 |
|---|---|
| 项目没有代码地图 | 自动调用 `project-code-map` 建图：项目概览、业务定位索引、本次审查相关的关键链路；其他模块按已识别／未覆盖区分 |
| 地图存在，目标与依赖仍有据且内容一致 | 复用导航并核实源码；不调用生成流程，不写入无变化的地图 |
| 地图缺少本次目标模块／链路 | 补齐当前目标及必要依赖，更新索引；不重建已核实的其他模块 |
| 相关结构、调用关系或关键执行边界变化，或地图已经指错位置 | 调用增量更新，重查影响到的关系、分支和索引；不能只改行号或路径 |
| 旧基线不可比较或地图缺少版本证据 | 定向重读当前目标与依赖，刷新相应证据和基线；未重查部分保持原状态或标为待复核，不直接宣布整图失效或全部最新 |

**“变化较大”按逻辑影响判断，不设固定行数／文件数门槛。** 以下变化影响当前目标或其公共依赖时，需要刷新相应地图：模块新增／拆分／迁移／删除，真实入口或装配实现切换，接口／事件注册及消费者变化，状态归属／生命周期／同步异步顺序变化，配置来源／选择路径变化，资源结算或保存／恢复边界变化。单行订阅改动也可能满足条件。

纯格式、注释或与目标及公共依赖无关的改动不触发重建。小范围参数／条件修改先核实已有记录；若图中对应的条件或数据事实已不一致，也只修订相关条目，不以改动小为由保留错误导航。

## 执行与续接

- 调用时传入项目根、审查目标、外部目标位置／用户指定位置、已找到的地图入口、触发建图／更新的依据及受影响范围。这一辅助调用已包含相应导航文档的写入任务，无需再次请求用户授权；不扩大为业务代码修复、项目指导或 Git 忽略设置修改。仓库内旧图可只读复用；需要维护时默认只写外部地图，用户明确指定其他位置时优先遵循。
- 首次覆盖先满足当前审查的定位需要，不要求把大型项目所有玩法画完才能审查。建立／更新必要导航后继续需求核对与代码追踪；审查中发现其他相关变化时合并补充，避免逐条发现都重复重建。
- `project-code-map` 返回后，由当前审查流程继续工作，不递归调用 `game-code-review`。地图不代替源码证据，不将建图成功写成逻辑验证通过；缺陷仍按主文件问题报告规则输出。
- 在结尾的范围说明中简述地图“新建／更新／复用／跳过”、入口及本次维护范围；未重查模块与审查未覆盖项如实保留。
- 稳定性审查按 [C4 证据沉淀](stability-sdk-review-checklist.md#c4-validation)补充相关平台的所有权、线程、恢复责任与历史风险入口；保留“现象已复现／根因待验证”的区别。下次从这些入口定向核对，不重做无变化的全项目地图。
- [问题台账](issue-tracking.md)使用独立的 `review/issues.md` 保存问题编号、用户处理决定和修复历史。地图只引用必要入口或编号，不维护另一份问题状态；传给建图辅助的范围明确排除台账重写，重建地图不得删除或覆盖 `review/`。地图失败不影响已定位台账的独立维护。

## 不可写或无法建图时

- 用户当次明确要求只读或禁止任何文件写入时，不写地图、不重复追问许可；继续从源码审查，并说明缺图或过期限制。仅要求“不改项目文件”仍可在项目外维护地图。
- 项目根无法确定、只有粘贴片段或所需仓库不可访问时，不把当前工作目录当成目标项目。按已有材料继续可完成的审查，缺失范围另列。
- 辅助技能未安装、外部目录不可写或生成失败时，简述原因并回退到直接源码定位；不回退为项目内写地图，不自动下载安装依赖，也不让地图问题阻塞原审查。辅助技能可用不代表运行环境、外部回调或完整游戏已验证。
