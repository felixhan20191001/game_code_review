# 多语言检查报告

## 本次结论

说明项目、版本/工作区、扫描日期和范围；分别写确定数据差异、已确认玩家问题、待复核风险。关联父技能既有编号和用户决定；无实测时明确说明。

## 确定问题／待验证风险

每项包含：

- **标题与影响程度**：以玩家现象命名；未闭合玩家影响时标为数据差异或候选。
- **问题与影响**：发生条件、可能看到什么、影响什么；未知部分说明。
- **预期与实际**：给规则依据，静态文件结果与实际游戏结果分开。
- **验证方法**：有依据的入口、动作和观察结果；入口未知时给文件核对和技术验证方向。
- **验证状态**：沿用父技能，未运行不能写已实测。
- **原因和证据**：一句通俗解释，附 Key、语言、单元格/源码、字体或参数差异。

## 候选与覆盖限制

汇总同文候选、未闭合引用、静态覆盖不足等；说明 Agent 复核范围、动态 Key/字体、实际包和展示未覆盖项。列出读取/解析失败及受阻项，不把未检查算通过。

## 检查依据

链接完整 JSON，说明记录数、语言、字体和引用范围。正式问题链接既有台账；本报告不创建第二套 ISSUE 编号。
